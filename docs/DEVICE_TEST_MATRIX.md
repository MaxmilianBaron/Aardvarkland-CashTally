# Minimální testovací matice zařízení

## Android

- API 24, malé rozlišení a 2 GB RAM,
- API 26–28, zařízení bez optické stabilizace,
- API 30–32, běžný telefon střední třídy,
- API 33–35+, moderní zařízení s runtime oprávněními,
- Samsung One UI, čistý Android/Pixel a alespoň jeden další výrobce,
- telefon i tablet, portrét i landscape,
- zamítnutí kamery, trvalé zamítnutí a návrat z Nastavení,
- Free po přijetí i odmítnutí UMP souhlasu, opětovné otevření voleb soukromí,
- testovací banner pouze na dashboardu, historii a nastavení,
- Ad-free bez inicializace nebo požadavku reklamního SDK,
- jednorázový nákup, zrušení, pending platba, refundace, reinstalace a obnova.

## iPhone a iPad

- nejstarší zařízení schopné iOS 13 v pilotní sadě,
- malý displej 320/375 bodů,
- současný iPhone s více zadními kamerami,
- iPad v portrétu i landscape,
- iOS 13, jedna mezilehlá a aktuální hlavní verze,
- zamítnutí kamery a návrat aplikace z pozadí,
- UMP souhlas, případně ATT pouze pokud jej skutečná konfigurace vyžaduje,
- Free s bannerem a Ad-free bez reklamního požadavku,
- Sandbox non-consumable, Ask to Buy/deferred, refundace a Restore Purchases.

## Společné scénáře

- přerušení hovorem nebo zamknutím během otevřené kamery,
- vypnutí internetu před spuštěním,
- aktualizace aplikace se zachováním historie,
- přechod Free ↔ Ad-free bez změny funkčního rozsahu nebo dat,
- plné úložiště zařízení,
- tmavý režim a zvětšené systémové písmo,
- deset rychlých skenů za sebou,
- každá měna, každý nominál a obě strany bankovky.
